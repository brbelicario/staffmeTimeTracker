SMTracker by B. Belicario

Privacy Policy

Last updated: September 15, 2026

SMTracker is an independent time-tracking tool. It is not made by, sponsored by, or affiliated with StaffMe.

What this policy covers

This policy explains how the SMTracker browser extension and its companion time-tracker dashboard handle information when you choose to use them.

Information the extension handles

After you give permission in the extension's on-page disclosure, SMTracker reads only the StaffMe hourly-work data needed for the tracker, such as the displayed date, time, worked-hour value, and related hourly metrics. It may read the response that renders that hourly table so the same rows can be captured when the table is inside StaffMe's page preview.

The extension stores normalized hourly rows, a sync timestamp, and diagnostic status in Chrome's extension storage. It does not read passwords, cookies, authentication tokens, general browsing history, or unrelated page content.

How the information is used

The information is used only to make hourly rows available to the SMTracker dashboard so it can calculate total work hours, coverage, weekend adherence, contract progress, and pay estimates. The dashboard may request the stored rows when you press Refresh data or when its optional auto-refresh feature is enabled.

Dashboard and cloud synchronization

If you use the companion dashboard's sign-in and cloud-sync features, the dashboard may also process the email or username you enter, tracker settings, manual hour entries, contract settings, weekly metrics, and the captured hourly rows. This lets your tracker profile be restored across devices. The extension itself does not collect your StaffMe password or StaffMe session credentials.

Sharing and limited use

Captured rows are made available to the companion SMTracker dashboard. If you enable cloud sync, the dashboard stores the tracker profile with its hosting and database providers so that the service can operate. We do not sell this information, use it for advertising, or use it for credit, insurance, employment, or unrelated profiling decisions.

SMTracker's use of information received from StaffMe pages and other user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the disclosed time-tracking feature and is not transferred for unrelated purposes.

Storage, retention, and deletion

The browser copy remains in Chrome extension storage until you clear the extension's data or remove the extension. If you use cloud synchronization, the dashboard profile remains available for the service to restore your tracker until it is deleted. To request deletion of cloud-synchronized tracker data, email br.belicario@gmail.com.

Security

The dashboard is served over HTTPS, and network requests used for cloud synchronization are sent over HTTPS. No online service can guarantee absolute security, so please use the extension only on devices and accounts you control.

Changes and contact

If the data practices change, this page will be updated before the change is used in the product. Questions about this policy can be sent to br.belicario@gmail.com.
